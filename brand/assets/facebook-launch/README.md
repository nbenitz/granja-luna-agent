# Activos de lanzamiento para Facebook

Estado: `pending_review`

## Perfil

- `profile-logo-v1.svg`: símbolo vectorial maestro.
- `profile-logo-v1.png`: exportación de 1024 × 1024 para subir a Facebook.

El símbolo combina la luna con un pollito de forma simple. Se diseñó sin texto para conservar
legibilidad en el recorte circular y en miniaturas pequeñas. No reemplaza una futura validación de
marca completa; funciona como identidad coherente y utilizable para lanzar la página sin seguir
postergándola.

## Wordmark

- `wordmark-v1.svg`: versión horizontal para documentos, piezas y futuras aplicaciones.
- `wordmark-v1.png`: exportación raster de 1600 × 520.

El subtítulo del wordmark es descriptivo y no debe tratarse todavía como eslogan oficial.

## Vista previa

- `page-preview.html`: composición local para comprobar el recorte circular y la relación entre
  perfil y portada.
- `page-preview.png`: captura de referencia; no debe subirse como portada ni como publicación.
- `content-preview.html` y `content-preview.png`: lámina de revisión de los primeros contenidos;
  tampoco deben publicarse.
- `video-pollitos-preview.jpg`: fotograma de revisión del video, no pieza editorial independiente.
- `cover-options.html` y `cover-options.png`: comparación de la portada original, el retoque mínimo,
  la alternativa de gallinas caseras y la composición editorial en pastura; no deben publicarse.

## Restricciones

- No deformar el símbolo.
- No agregar productos, precios ni promesas al logo.
- Mantener margen alrededor del pollito y la luna.
- Para Facebook, usar PNG porque la plataforma puede recomprimir logos y texto.
