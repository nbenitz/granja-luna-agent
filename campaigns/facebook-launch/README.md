# Campaña: lanzamiento de Facebook

Estado: `draft`

## Resultado esperado

Publicar una página completa, coherente y con suficiente contenido inicial para que una persona pueda
entender qué es Granja Luna, qué vende actualmente y por qué vale la pena acompañar el proyecto.

## Alcance del MVP

- Identidad y descripción de página.
- Foto de perfil provisional o logo aprobado.
- Portada con fotografía real.
- Seis publicaciones iniciales.
- Respuestas preparadas para consultas frecuentes.
- Aprobación humana de cada elemento.

No incluye publicidad paga, publicación automática ni integración con credenciales de Meta.

## Orden

1. Importar fotografías antiguas candidatas a `media/inbox/`.
2. Crear una planilla simple de selección y procedencia.
3. Detectar y fotografiar únicamente los faltantes.
4. Elegir una de las rutas visuales.
5. Preparar avatar, portada y plantillas.
6. Revisar las primeras seis publicaciones.
7. Crear y asegurar la página.
8. Publicar el contenido aprobado durante dos o tres semanas.
9. Registrar preguntas, consultas y métricas para ajustar la estrategia.
